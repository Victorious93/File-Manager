Copyright for the jackpal / Termux terminal libraries: see the upstream NOTICE /
source headers in the terminal-emulator and terminal-view modules of
https://github.com/termux/termux-app (tag v0.118.3).

This app loads the native library `libtermux.so` (forkpty / PTY resize) from the
terminal-emulator AAR. If that library fails to load, the app falls back to its
own pipe-based shell (no PTY, limited ANSI).
